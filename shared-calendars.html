Share one calendar. Keep everyone current.

A shared calendar is a .jewcal file. Send the file once for a manual import, or put it at a stable HTTPS link so other people can subscribe to updates.

Create and publish Use or subscribe Try the test calendar

For calendar owners

Create and publish a shared calendar

  1. Create it. In JewCal, open Settings → Shared calendars → New calendar and give it a clear name.
  2. Add events. When creating or editing each event, select the new calendar in the Calendar field.
  3. Export it. Return to Shared calendars, open that calendar’s menu, choose Export, and save the .jewcal file. Add a password only if every subscriber should need it.
  4. Share it. Send the file for a one-time copy, or upload it to a public HTTPS address for automatic subscriptions. GitHub Pages, a static website, or any direct HTTPS file host works.
  5. Publish updates. After changing events, export again and replace the file at the same HTTPS address. Keep the password choice unchanged; subscribers refresh automatically about every six hours and can also refresh manually.
Important: Anyone with an unprotected link can read the calendar. A password protects the file contents, but share the password separately from the link.

For calendar members

Use a shared calendar

Subscribe to a link

  1. Copy the HTTPS calendar link.
  2. Open Settings → Shared calendars → Subscribe to network calendar.
  3. Enter a local name, paste the link, and enter the password if the owner supplied one.
  4. Tap Subscribe. The calendar appears read-only and stays updated.

To fetch an update now, open the calendar’s menu and choose Refresh. Its visibility switch hides events without unsubscribing.

Import a file once

  1. Save the received .jewcal file.
  2. Open Settings → Shared calendars → Import calendar.
  3. Select the file, unlock it if asked, then import it as a new calendar.

An imported file is an editable snapshot. It does not receive later changes from the owner.
